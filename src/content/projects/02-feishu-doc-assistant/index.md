一款飞书文档内的 AI 写作插件：选中任意段落即可调用大模型进行续写、润色、总结和翻译，结果直接写回文档。

## 解决的问题

在文档里写作时频繁切换到大模型网页复制粘贴，打断心流。把 AI 能力嵌入文档编辑器，让润色和续写原地完成。

## 核心功能

- **划词唤起**：选中文字后弹出操作菜单（续写 / 润色 / 简写 / 翻译）
- **原地替换**：生成结果以修订形式插入，支持一键撤销
- **全文总结**：对长文档生成结构化摘要，插入文档开头
- **自定义指令**：支持保存个人常用的 Prompt 模板

## 技术要点

- 基于飞书文档 API 实现内容的读取与写回，处理并发编辑冲突
- 流式输出：SSE 逐字渲染生成过程，降低等待感
- Prompt 模板管理：JSON 配置驱动，不写代码即可增删指令
