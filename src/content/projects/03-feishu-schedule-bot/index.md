群里一句话「帮我约下周和产品会对齐一下」，机器人自动收集参会人空闲时间、创建日历日程并发送会议邀请。

## 解决的问题

组会协调时间在群里来回 @ 人确认，常常拖一两天。机器人把这件事压缩到一分钟内完成。

## 核心功能

- 自然语言解析会议意图（时间范围、参会人、主题）
- 调用飞书日历 API 查询全员空闲时段，找出最优时间
- 自动创建日程、预订会议室（如有冲突自动换备选时间）
- 会前 15 分钟在群里推送提醒

## 我的职责

独立负责自然语言意图解析模块与日历 API 的调度逻辑。
